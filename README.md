# 공공기관 인력·보상·복지·재정 현황 대시보드 


## 폴더 구조

```text
(리포지토리 최상위)
├─ 종합현황.py              ← 메인 실행 파일 (Streamlit Cloud의 "Main file path"에 이 파일을 지정)
├─ common_data.py           ← 모든 페이지가 공유하는 코드 (데이터 정제, 지표 계산, 차트, 필터)
├─ requirements.txt
├─ README.md
├─ 그밖의_복리후생제도_등의_운영현황.xlsx   ← 원본 엑셀 10개 
├─ 기관장업무추진비.xlsx
├─ 법인세정보.xlsx
├─ 복리후생비.xlsx
├─ 수입지출현황.xlsx
├─ 신규채용현황.xlsx
├─ 일가정_양립_지원제도_운영현황.xlsx
├─ 임원연봉.xlsx
├─ 임직원수현황.xlsx
├─ 직원평균보수현황.xlsx
└─ pages/                    
   ├─ 2_인력_채용.py
   ├─ 3_보수_임원.py
   ├─ 4_일가정_양립.py
   ├─ 5_복리후생.py
   ├─ 6_수입_지출.py
   └─ 7_기관_상세.py
```

파일 이름 맨 앞의 숫자는 사이드바에 표시되는 순서를 정하는 용도입니다 (숫자와 언더바는 화면에는
표시되지 않고, 메뉴에는 "인력 채용", "보수 임원" 처럼 보입니다).



## 데이터 갱신하기

원본 엑셀 파일(같은 이름)을 새 걸로 교체한 뒤, 사이드바의 "🔄 캐시 초기화" 버튼을 누르거나
앱을 재시작하면 됩니다. 코드 수정은 필요 없습니다 (연도 열은 자동으로 인식됩니다).

## 알려진 한계

- 원자료에 기관코드가 없어 기관명을 기준으로 결합합니다.
- 정원 총계는 "임직원 총계(A+B+C)" 표기에서 역산해 정의했습니다 (임원 정원 + 일반정규직 정원 +
  무기계약직 정원).
- 총복리후생비(예산상 복리후생비 시트)와 항목별 세부내역(3-1~3-13 시트) 합계가 정확히 일치하지
  않을 수 있어 이중 합산을 방지하도록 별도로 관리했습니다.
- 청년/여성/장애인 신규채용은 중복 가능한 집단이라 합산해서 100%로 취급하지 않습니다.
- 공공기관의 '총수입'은 정부지원수입을 포함하므로 일반 기업 매출액과 다른 개념입니다.
