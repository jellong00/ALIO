# 공공기관 경영정보 대시보드

행정·정책대학원 석사과정 기초통계 및 기초계량 수업용 교육 대시보드입니다.
공공기관 경영정보 공개시스템(ALIO) 데이터를 활용하여 분포, 기초통계, 상관관계,
단순/다중회귀, 로짓 등을 직접 실습할 수 있도록 구성했습니다.

**원본 Excel 파일을 그대로 사용하며, 별도의 전처리·parquet 변환 과정이 없습니다.**
데이터는 Streamlit의 `@st.cache_data`로 앱 실행 중에만 메모리에 캐싱됩니다.

## 1. 환경 설치

```bash
pip install -r requirements.txt
```

Python 3.10 이상을 권장합니다.

## 2. raw Excel 위치

`data/` 폴더에 다음 원본 Excel 파일을 넣어주세요. (파일명 동일하게 유지)

```
수입지출현황.xlsx
법인세정보.xlsx
임직원수현황.xlsx
직원평균보수현황.xlsx
임원연봉.xlsx
신규채용현황.xlsx
복리후생비.xlsx
기관장업무추진비.xlsx
그밖의_복리후생제도_등의_운영현황.xlsx
```

`일가정_양립_지원제도_운영현황.xlsx`는 데이터 품질을 고려해 핵심 대시보드에서 제외했습니다.

## 3. 실행

```bash
streamlit run app.py
```

- 파일을 처음 열 때 각 데이터셋을 Excel에서 직접 읽어 정제하므로 첫 페이지 로딩에
  몇 초 정도 걸릴 수 있습니다. 이후에는 같은 세션 내에서 캐시된 데이터를 사용합니다.
- 원본 Excel 파일을 교체한 뒤에는 Streamlit 우측 상단 메뉴의 "Clear cache"를 누르거나
  앱을 재시작하면 최신 데이터가 반영됩니다.

왼쪽 사이드바에서 원하는 페이지로 이동할 수 있습니다.

- **01~11**: 데이터 개요, 기관 종합현황, 데이터셋별 현황(분포 중심)
- **12~16**: 요약통계 / 분포 / 집단별 분포 / 시계열 / 상관관계 실습
- **17~19**: 단순회귀 / 다중회귀 / 로짓 실습

## 프로젝트 구조

```
app.py
requirements.txt
data/
  raw/              원본 Excel (그대로 두고 수정하지 않음)
utils/
  data.py             원본 Excel 로딩·정제·기관-연도 패널 병합 (캐시 적용)
  stats.py            기술통계 + OLS/Logit 계량분석 함수
  charts.py           Plotly 재사용 차트 함수
  filters.py          공통 필터 UI (연도/기관유형/기관명/주무부처)
  components.py       공통 분포 분석 컴포넌트 (요약통계→히스토그램→...→연도별 변화)
  constants.py        공통 상수, 안내 문구
pages/
  01~19               각 분석 페이지
```

## 데이터 해석상 주의사항

1. 모든 데이터는 **기관 단위 집계자료**이며, 개인 수준 결과로 해석할 수 없습니다.
2. 상관관계와 회귀계수는 통계적 연관성을 보여줄 뿐, **인과관계를 의미하지 않습니다.**
3. 연도별로 기관 구성(신설·통폐합 등)이 달라질 수 있습니다.
4. **2026년 자료**는 연중 공시자료 또는 잠정값일 수 있어 기본 분석연도는 2025년입니다.
5. 법인세 `결정세액 / 과세표준`을 임의로 "실효세율"로 명명하지 않습니다.
6. 원자료에 없는 개념이나 변수는 추정해서 만들지 않습니다.
